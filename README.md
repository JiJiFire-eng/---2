# ---2 BirthdayStyler
Учебная программа для выполнения кейс-задачи №2 индивидуального задания по практике.

Цель проекта
Создать консольную программу, которая работает с датой рождения пользователя и выполняет несколько операций с датой, а затем выводит её в стилизованном виде.

Реализовано
последовательный ввод дня, месяца и года рождения;
проверка корректности введённой даты;
определение дня недели, которому соответствует дата рождения;
определение, является ли указанный год високосным;
вычисление текущего возраста пользователя;
защита от ввода даты рождения из будущего;
вывод даты рождения в формате дд мм гггг;
отображение цифр даты символами * в стиле электронного табло.
Технологии
Python 3;
стандартные модули Python для работы с датой и временем;
сторонние библиотеки не требуются.
Запуск
Требуется Python 3.10 или новее.

python main.py
После запуска программа последовательно запросит день, месяц и год рождения.
